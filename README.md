## v1.6 — 진행이 되돌아가는 버그 수정 (여러 크롬북·창)
- 원인: 같은 학생이 여러 크롬북·창에서 마을을 열면, 예전 상태로 켜져 있던 쪽이 저장할 때 서버의 앞선 진행(예: 5단계)을 덮어썼음. 그 뒤 다른 크롬북을 새로 열면 ‘더 늦게 저장된’ 낡은 마을(3단계)을 불러옴
- 고침
  - 저장할 때마다 판 번호(`rev`)를 1씩 올리고, 보안 규칙이 ‘서버 판 번호 + 1’인 저장만 받아 줌 → 낡은 창·예전 버전 게임은 덮어쓸 수 없음
  - 같은 마을이 다른 곳에서 더 새로 저장되면 이 화면은 멈추고 ‘이 마을이 다른 곳에서도 열려 있어요 → 여기서 이어 하기’
  - 크롬북을 켤 때·이어 하기를 누를 때 **더 많이 진행한 쪽(시대 → 푼 문제 → 플레이 시간)**을 남김 (예전: 더 늦게 저장된 쪽)
  - 다른 기기에서 이름을 바꿔도 번호·학급이 같으면 같은 학생으로 이어짐

## v1.2~1.3에서 새로 생긴 것
- **시대별 주민 옷차림**: 선사(가죽옷·창) → 삼국(점무늬 저고리·절풍) → 통일신라(복두) → 고려(백의·스님) → 조선(갓·쪽머리·패랭이·지게) → 근현대(교복·양복)
- **시대 돌파 보스전**: 시대마다 보스(한나라 대군 → 수나라 → 나당 전쟁 → 거란 → 임진왜란 → 양요 → 망각 대마왕). 정답 = 공격, 오답 = 내 하트 -1(하트 5개), 3연속 정답부터 필살 2칸
- **문제 738개 — 5학년 2학기 사회(2022 개정) 교과서 범위**: 1단원(선사~고려) · 2단원(조선 건국~개항) · 3단원(일제 강점~6·25 전쟁). 교과서 밖(민주화 운동, 경제 성장, 올림픽 등)과 지엽적인 문제는 `data-quizzes.js`의 `OUT` 목록으로 뺐어요. 차시별 새 문제는 `js/data-quizzes3.js`. 한 바퀴를 다 풀기 전엔 같은 문제가 다시 나오지 않음
- **60초 타임어택 대기 20분** (자격루 연구 1단계마다 -5분, 최소 10분)
- **친구 전쟁**: 설정에서 ‘전쟁 허용’을 켠 친구끼리만. 주민 모으기(30·60·100%) + 위인 참전(최대 3명, 장군 보너스) + **실력 퀴즈 5문제**(정답 +10%, 빨리 맞히면 최대 +15%) → 운은 ±5%뿐이라 작은 차이는 실력으로 뒤집혀요
  - 선전포고를 받으면 “전쟁하시겠습니까?” 창 → 거절 가능, 10분 안에 대답 없으면 취소
  - 진 쪽 건물 피해는 **확률**: 아슬아슬한 패배 40%로 1채, 확실한 패배 70%로 1채, 크게 지면 1~2채(25%로 1채 레벨 -1). 이긴 쪽도 접전이면 15%로 1채. **전쟁 배상금**(가진 엽전의 5/10/15%)을 이긴 쪽에 냄
  - 전투 장면: 1라운드 화살 공격 → 2라운드 돌격 → 3라운드 위인의 힘 → 깃발 쓰러짐·꽃가루 (약 8초, 건너뛰기 가능)
  - 하루 3번 선전포고, 전쟁 뒤 20분 보호, 두 시대 이상 약한 마을은 공격 불가
- **학급 채팅**(왼쪽 ‘채팅’): 욕설·전화번호·인터넷 주소 차단, 4초에 1번, 60자. 시대 돌파·전쟁 결과는 자동 알림
- **학급 랭킹**(왼쪽 ‘랭킹’ 또는 위쪽 별): 명성·퀴즈 정답·정답률·전쟁·콤보·유물·시대 진도
- 오른쪽 아래 Netlify 배지 자리를 비워 버튼이 가려지지 않게 함 (배지 자체를 없애려면 Netlify 유료 요금제 필요)

- **새 디자인 적용**: 배경 나무·바위 12종, 시대별 주민 42명 + 병사 7명, 버튼·판넬·타일·리본 11종 (img/scenery · people · ui)

## Firebase (온라인 저장)
- 프로젝트: `history-builder` (설정값은 `js/firebase-config.js`)
- 로그인: 익명 로그인 (학생 계정·비밀번호 필요 없음)
- 저장 위치: Firestore `villages/{학급코드}_{출석번호}` — 학생 1명당 문서 1개
- 학급 제어용 `classes/{학급코드}` 문서는 4차 교사 화면에서 쓰기 예정 (지금은 쓰기 막힘)
- 인터넷이 안 되면 자동으로 크롬북 안에만 저장하고, 연결되면 다시 올립니다.
- `firebase-config.js`를 비우면 학급 코드 없이 로컬 저장 모드로 돌아갑니다.

- **문제당 기본 KP**: 10 / 18 / 28 / 50 / 110 / 170 / 280 (기획서: 10 → 35 → 120). 건물 KP 가격은 기획서 그대로 유지
- **돌파 조건에 ‘그 시대 건물 N종 건설’ 추가** (3~6단계) — 새 시대 건물을 건너뛰고 돌파하는 것을 막음
- **건물 수익을 시대가 갈수록 느리게** — 엽전이 넘쳐 레벨업이 의미 없어지는 문제 해결
- **불국사는 3단계(통일신라)로 이동** — 751년 통일신라 때 지은 절이라 고증에 맞춤. 2단계에는 고구려 대표로 광개토대왕릉비를 넣음
- 돌파 응시료는 **성공할 때까지 한 번만** 냄 (실패해도 바로 재도전)
- 꽉 찬 마을을 위해 **건물 철거**(엽전 50% 환급)와 **자리 바꾸기** 추가

시뮬레이션 결과(연속 플레이 기준, 정답률별): 70% → 약 26시간 · **80% → 약 18시간** · 90% → 약 14시간

## 그림 바꾸기 (제미나이)
1. `그림만들기도우미.html`을 더블클릭해서 열어요 (크롬).
2. 시트 15장의 프롬프트를 차례로 제미나이에 붙여 넣고, 나온 그림을 도우미에 끌어다 놓아요.
3. `img.zip 저장` → 압축을 풀어 나온 `img` 폴더를 이 폴더(index.html 옆)에 넣고 다시 배포해요.
- 그림이 없는 항목은 코드로 그린 도트 그림이 그대로 나와요. 건물 시트 4장만 해도 마을이 확 바뀌어요.
- 게임은 `img/list.json`에 적힌 그림만 불러와요 (도우미가 자동으로 만들어 줌).

- **새 디자인 시트 10장**(맨 위 D1·P1~P7·U1·U2): 배경 나무·바위(`img/scenery`), 시대별 주민 6명+병사(`img/people`), 버튼·판넬·타일·리본(`img/ui`). 그림이 있는 것만 바뀌고, 없는 것은 원래 모양 그대로예요.
- 새 시대 보스 4종(한나라·수나라·당나라·망각 대마왕)은 지금 코드 그림이에요 → 도우미의 **X2 시트**로 뽑으면 바뀌어요.
- 지금 들어 있는 그림 중 청자 상감운학문 매병(r4_5)·앙부일구(r5_3)는 코드 도트 그림이에요 → 도우미의 **R4 시트**로 다시 뽑아 주세요.
